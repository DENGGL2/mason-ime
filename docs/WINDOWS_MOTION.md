# Windows 输入动效验收版

设置界面延续 Mason 2.4.6 的稳定布局。2.4.7 增加柔性词频学习开关，页签保持原位置和即时响应。

| 内容 | 缩放 | 时长 |
| --- | --- | --- |
| 候选窗弹出、新增拼音字母 | 0.9 → 1.1 → 1 | 200 ms |
| 新出现或变化的中文、英文、完整表情候选 | 原字形大小，不缩放 | 约 107 ms |

候选窗和新增拼音字母的透明度使用 0.4 → 1，中文、英文和完整表情候选内容的透明度曲线使用 0.8 → 1，约 107 ms 完成。首次弹出的内容仍受整个候选窗渐显动画约束；保持原来的透明度叠加补偿。候选字形在弹窗缩放后按原尺寸绘制，内容尺寸保持固定；相同内容和高亮改变保留时间进度。选词、退格和收起立即响应。

本轮定位到真正的输入阻塞：创建每个原生布局时反复检查数百个函数地址，测量用的布局也触发检查。改为按原生类缓存完整函数表与 RTTI 前缀，内存和执行属性按区域验证；对象的文本和标红范围仍独立保存和释放。

帧调度采用局部高精度等待计时器，工作线程仅发送窗口消息，绘制保留在原 UI 线程。最多保留一个待处理帧，唯一令牌排除关闭或重开后的旧消息，动画结束即停止计时并释放线程、事件和计时器句柄。不会改变系统计时精度。首帧重复呈现、每帧重复隐藏底窗和显示临时窗也已移除。

以下为 2026-11-19 调整透明度之前，同机可见的真实 TSF 客户端测量，包含引擎响应，帧间隔为实际呈现调用间隔中位数；不将软件合成微基准当作流畅度结论。

| 架构 | 首次按键 | 连续按键中位数 | 呈现间隔中位数 |
| --- | --- | --- | --- |
| x64 | 500.7 → 277.3 ms | 198.7 → 20.5 ms | 22.8 → 16.7 ms |
| x86 | 613.0 → 279.7 ms | 325.3 → 22.7 ms | 29.8 → 16.7 ms |

首次按键的约 250 ms 延迟位于开始绘制之前。2026-11-20 的调用分段测量进一步确认，主要耗时来自默认 Direct2D DC 绘制目标的设备初始化，连接和字体工厂本身耗时很短。

候选窗先在内存位图内绘制，再交给 GDI / 分层窗口呈现。Mason 自身工厂创建的默认 DC 绘制目标改用软件绘制，保留原有像素格式、透明度、DPI 和其他属性；明确指定的绘制目标类型继续按原参数创建。如果软件目标创建失败，自动回退到原来的完整参数。此改动不增加后台预热线程，也不修改宿主应用的绘制工厂。

以下为 2026-11-20 同机独立 TSF 客户端进程测量，首次按键包含完整按键处理和引擎响应；优化后数据来自最终构建，未装入额外诊断组件。

| 架构 | 首次按键优化前 | 首次按键优化后 | 连续按键中位数 |
| --- | --- | --- | --- |
| x64 | 289.6 ms | 41.6 ms | 19.8 ms |
| x86 | 271.7 ms | 43.6 ms | 20.0 ms |

分段诊断中的 DC 目标创建从约 227–246 ms 降至约 8–9 ms。测量针对每个新进程的首次输入，系统本身未重新启动；具体软件的负载和输入线程调度仍会影响耗时。

x64/x86 原生及真实 TSF 验证通过：候选内容仅透明度渐显且无缩放、英文与完整组合表情、原有点击区域、高亮不重播、连续输入、错误拼音标红、立即关闭和快速重建后的资源释放。动效优化时保留稳定设置布局、用户配置和默认输入法；本机绘制组件及安装清单已更新，动效优化阶段先在本机验收；2.4.7 正式版包含这些改动。已打开的应用会保留原先加载的组件，重新打开后加载优化版。

2026-11-20 用户已验收首次输入不卡顿，优化版保留在本机安装与源码中。保存设置后底层服务的进度、成功气泡提示已拦截；菜单和托盘回调继续转发，故障警告仍可显示。用设置后端的实际部署流程验证成功，观察到原生部署气泡经过拦截，设置程序、用户配置和纠错代码均未改变。

Mason 2.4.7 将已验收的动效、首次输入优化、保存成功提示处理和简拼学习一并发布。已有软件可能保留旧输入组件；重开该软件可加载新版，需要统一刷新时可保存工作后注销再登录。
