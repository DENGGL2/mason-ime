# 简拼、纠错与选词学习方案

日期：2026-11-20。状态：用户已确认，实现与隔离引擎验证完成。

## 结论

同时采用“合法简拼优先”和“主动选词学习”。简拼保护负责让第一次输入就不误标，选词学习负责记住用户习惯。设置 → 输入 → 纠正输入错误中新增“柔性词频学习”开关，默认关闭。

开关副文本：**开启后根据输入频次权重修改排序，关闭则默认2次选择会自动置顶**。

- 关闭：同一原始编码下，主动选择同一完整候选并上屏两次，后续输入该编码时保证该词为首项。
- 开启：结合当前候选质量与选择频次提升排序，不使用固定次数的强制置顶规则。
- 切换模式保留同一份选择记录。关闭纠错时，不再重新插入已学习的纠错候选；普通简拼学习仍可使用。

## 当前原因

- `mason_correction.lua` 的合法性检查主要识别完整拼音音节。`shh`、`shid` 的末尾声母属于合法简拼或混合输入，但不能通过这个完整音节检查。
- 原始词库候选还必须达到固定的质量门槛才会阻止纠错。简拼候选分数可能较低，因此纠错候选会抢到前面，选中的纠错候选携带红色字母标记。
- 纠错查询使用只读词库组件，不读取个人词频；输出的 `mason_correction` 候选也没有可学习的词典条目。这保护了词库，却使该分支不能学习反复确认的选择。
- 主拼音翻译器已有 Rime 用户词典学习，但它采用加权排序；白霜的固定置顶过滤器也会影响顺序。该机制自身不保证固定次数后成为首项。

## 建议优先级

| 优先级 | 内容 | 标红规则 |
| --- | --- | --- |
| 1 | 当前编码下，用户已经明确确认的常用候选 | 原始简拼候选不标红；真正的纠错候选保留错误字母标记 |
| 2 | 原输入能完整匹配的全拼、简拼、混合拼音及自定义短语 | 不把简写的声母视为错字 |
| 3 | 相邻键纠错建议 | 缺少有效原始候选时优先；已有合法简拼候选时排在后面 |

合法性以 Rime 的拼音规则和原始词库匹配为依据，而非简单地按字符长度猜测。不能把任何可以自动拼接成一句话的结果都当成合法原词，否则真正的错拼也会被误放行。

| 输入 | 预期处理 |
| --- | --- |
| `shh` | 支持“时候”等词的简拼，不标红末尾 `h`；记住用户明确选择后，可优先显示“时候” |
| `shid` | 支持“是的”等词的全拼与简拼混输，不标红末尾 `d` |
| `nigapsuwo` | 保留“你告诉我”的纠错能力和 `p` 的红色标记 |

## 主动选词学习

默认规则：同一编码下，用户主动选择同一候选并完整上屏两次后，后续输入该编码时将该词放在首位。原有词频学习可以在第一次选择后改变顺序，但新增规则在第二次明确选择后才保证首位。

- 以“方案、简繁等转换状态、原输入编码、确认的候选”区分记录。例如 `shh → 时候` 与 `shid → 是的` 互相独立，也不会把简体的历史候选插进繁体模式。
- 数字选词、鼠标选词或主动移动到其他候选后确认可以计数。直接接受系统自动给出的首项，不视为主动纠正排序的证据。
- 翻页、浏览候选、取消输入、删除字母和未完成的组合不增加次数。
- 其他词达到两次明确确认后，最近确认的偏好可以替换原来的置顶项。
- 纠错候选可以学习其正确中文偏好，但不能把错误拼音直接加入主用户词典。保持原始输入和错误字母的显示逻辑。
- 选择记录只存在本机的 `用户数据/mason-learning.tsv`。服务初始化时加载，按键处理使用内存中的记录，仅在明确确认并上屏后追加记录。

## 实现

- `mason_correction.lua`：只读词库能完整匹配原始全拼、简拼或混合拼音时，不再要求任意质量门槛。仍排除任意自动拼接的句子和未完成的候选。
- `mason_learning.lua`：独立的本机原始编码选择记录。通过真实的提交事件确认选词；数字、鼠标及浏览后确认可记录，直接接受自动首项、取消、单纯翻页、原始拼音提交和应用失焦提交不记录。
- `mason_preedit.lua` 与最终的 `mason_candidates.lua`：复用已有处理器和过滤器，不新增冲突的列表补丁。
- 强制模式保留原始候选及其元数据；已确认的词超出前 96 个惰性候选时可恢复为独立候选，不污染主词库。
- 柔性模式以当前质量为基准，使用有上限的对数频次权重处理前 64 个候选；未学习候选之间的相对顺序保持不变。

设置使用已有 Material 开关组件和稳定的页面布局。现有候选窗、拼音与候选文字动效保持原实现；保存成功时不显示系统进度气泡。

## 验证

使用当前安装的 Rime 1.13.1 DLL 和私有测试词库，没有往个人词库写入测试选择。验证覆盖 `shh → 时候`、`shid → 是的`、`nigapsuwo → 你告诉我` 及 `p` 的红色标记，两次置顶、柔性权重、候选分页、计数去重、取消、转换状态隔离和新进程中的记录恢复。设置开关的默认值、保存、恢复默认、原有标题位置及保存后的静默表现也已验证。
