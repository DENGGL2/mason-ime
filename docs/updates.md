# 更新流程（2.4.9）

本次基于 GitHub 的 2.4.8（`ec2fa595fe42a04492f69e28d250037a7c66d2a2`）修改，包含该版本修复的原生界面安装流程。

## 程序更新

指南的“检查更新”发现正式新版时，显示“立即更新”和“取消”。选择立即更新后，在设置窗口内下载，显示进度、已下载大小、总大小和网速。可以取消；网络中断会重试，失败时也可手动重试。

下载后检查 GitHub 提供的 SHA-256、安装清单、版本和每个文件的校验值。全部通过后自动打开图形升级窗口，等待旧设置窗口退出，再沿用已安装目录覆盖。复用现有引擎，保留个人词库、模糊音、纠错、选词学习记录、外观和简繁设置，并生成恢复备份。

## 通知与红点

后台每六小时检查一次；重启服务时沿用检查时间，避免重复请求。每个程序或词库版本只发送一次 Mason 的系统通知。点击程序通知打开设置的指南并定位检查更新按钮；点击词库通知打开输入页并定位更新词库按钮。设置窗口保持单实例。

有程序更新时，指南及检查更新按钮显示低饱和度红点；有词库更新时，输入页及更新词库按钮显示红点。原有 Windows 输入法栏图标提示未读更新，右键菜单的对应更新项也显示红点。打开右键菜单后清除图标红点，菜单和设置里的红点保留到完成更新；下一个新版本会再次产生未读提示。

红点绘制在原有语言栏组件中，不创建独立托盘入口。系统通知使用 Mason 自己的名称和通知入口。

## 词库连接错误

网络失败、服务暂时不可用和下载中断会重试；GitHub 匿名接口达到限制时，改用公开发布页获取最新版本与校验值。失败提示保留具体原因，详细记录位于安装目录的 `日志/更新记录`。

## 验证

- Python 更新测试覆盖网络重试、限流、校验失败、异常路径、逐文件验证、固定升级路径和通知去重。
- WPF 隔离测试覆盖红点、立即更新/取消、下载进度及网速、取消后不安装、校验后只交接一次。
- x64/x86 真实 TSF 组件测试覆盖图标红点、两类菜单更新红点、右键已读，以及新版词库出现后恢复提示，未执行打字。
- 安装核心隔离验证保留八项用户内容、原安装位置、繁体默认和恢复备份，复用已有引擎。

已打开的软件可能仍持有旧输入组件，重新打开该软件可以加载新版；统一刷新可以保存工作后注销并重新登录 Windows。
